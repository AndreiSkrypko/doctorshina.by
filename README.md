# DoctorShina.by

Сайт мобильного шиномонтажа в Минске.

- **`web/`** — актуальный сайт на Next.js (App Router). Запуск: `cd web && npm install && npm run dev`
- **Корень** — legacy PHP-версия (архив)

## Деплой Next.js

```bash
cd web
npm run build
npm start
```
